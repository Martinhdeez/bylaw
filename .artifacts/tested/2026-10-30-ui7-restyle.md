# UI7 restyle

Branch `view/ui7-restyle`, PR #46 into `bylaw/build`. The user approved it on 2026-10-30, as it stood at 2560b9f, covering the colours, the logo and the wider Live view. It changes the views only. There is no API or behaviour change, except for the two copy fixes below.

## What changed

- **Type:**
  - One family: Fira Sans 400–600, with tabular figures. Fira Code is used only for literal code.
  - Sentence case.
  - No dockets, article numerals or § marks.
  - Tool names read as words outside the trace's literal call.
  - No cream paper panels.
  - Domain display names in headings, for example "the customer service policy". The Audit picker fits 3 cards, and the ⌘K palette reaches every domain.
- **Palette:**
  - Dark theme: an indigo near-black base (#0f1122) with indigo surface steps.
  - Light theme: a cool lavender-tinted base.
  - Violet is the brand: primary buttons (violet to blue), the current nav item, focus rings and the selected domain. Muse uses a lighter violet.
  - Blue is the second accent: links, the Live transport and the customer's chat bubbles.
  - Other accents carry meaning: nav icons, report stat cards, amendment metrics, and soft washes behind the titles.
  - Verdicts stay green, red and amber.
- **Moments:** each lasts 240–280 ms, runs only on a state change, and is off under `prefers-reduced-motion`.
  - The Ratify button has a gradient.
  - The RATIFIED stamp scales in with a glow.
  - Live's "Blocked before it ran" pill.
  - The $280 and $0 result figures have gradients.
- **Brand:**
  - The Live top brand bar is removed. The tagline stays as a small line above the headline.
  - The sidebar logo is larger: a 42px mark and a 26px wordmark.
  - `Logo()` is byte-identical to the original.
- **Live:**
  - Wider: up to 1640px above 1240px, with the chat column growing first.
  - The chat pane is white in both themes.
  - Agent markdown (bold, bullets and paragraphs) renders as React elements, never as HTML.
  - The guarded headline says "stopped" only once the block has happened.

## Contrast

`web/scripts/contrast.py` checks every text pair in both themes. It composites the soft washes over their base at full alpha, including stacked washes. All text is at least 4.5:1, and large figures are at least 3:1.

Review round 1 found the first two failing pairs below; the script found the third:

- **Blocked pill:** it now uses coral #ff8a7a in dark (4.84:1) and #a3260b in light (5.47:1).
- **Light trade-off label:** it is now #7a4400 (5.85:1).
- **RATIFIED stamp:** it drops its own wash, so its date is 7.48:1 in dark and 4.76:1 in light.

## How to check

```
cd web && E2E_MOCK=1 npx playwright test
```

`E2E_PORT=<port>` runs the dev server on its own port. To take the review screenshots, add `SHOTS_DIR=<dir>`, plus `SHOTS_THEME=light` or `SHOTS_DOMAIN=csdemo`:

```
E2E_MOCK=1 npx playwright test e2e/shots.spec.ts
```

New tests are in `e2e/live.spec.ts`:

- Markdown renders as bold and bullets, and an injected `<img>` shows as text.
- The headline changes before and after the block.
