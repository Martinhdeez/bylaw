# OP1 Reproducible simulator setup

- `make setup` clones tau2-bench (MIT) into `.context/tau2-bench` at the commit pinned by `TAU2_COMMIT` in `Makefile`, if missing, then runs `uv sync`, then `npm ci` in `web/` when `web/package.json` exists.
- `make check` (pytest, then `npm run build` in `web/`) fails fast with "Run 'make setup' first" when the clone is missing.
- `README.md` gets a Quickstart section.

To test: in an empty directory, `git clone` the repo, `make setup`, `make check`. Evidence: `.scratch/after/op1-setup/fresh-clone.txt` (local, gitignored).

To bump tau2: change `TAU2_COMMIT`, delete `.context/tau2-bench`, run `make setup`.
