# UI2 Web UI wired to the API

- Every screen in `web/src/` reads the C9 API (`/api/*`, Vite dev proxy to `localhost:8000`, override with `BYLAW_API`). No fixture import remains in `src/` (REQ-UI2-1).
- Routes carry the domain and the C4 v1.2 hole key: `#/`, `#/<domain>/report`, `#/<domain>/holes/<key>[/amendment]`, `#/<domain>/bench`.
- Audit streams C9 progress events through five phases (compile, search, verify, amend, backtest). Muse labels follow each event's `muse` flag, `run.mode`, and the presence of amendments.
- Report groups Class A holes by forbidden goal and links every entry to its hole page (C9 v1.2). Under 01 v1.7 it shows Class A first, then a "Policy vs practice" section for Class B `contradictions` with the gold task ids as evidence ("τ² grades this as correct in task 7"), then Class C. Class B is amber; red only marks a Class A hole. Net paid out sums Class A only and comes from the report.
- Class B hole page says which gold tasks take the chain; its amendment shows the trade-off (the gold tasks the rule blocks) next to Ratify.
- Hole page: step-by-step trace replay (previous, next, replay), rule verdicts with the quoted policy line and its `policy.md` line number, the goal from `/api/ratified` `forbidden_goals`, the C4 v1.2 diff.
- Amendment: C7 policy text, rule patch, rationale, backtest (newly blocked = `blocked - baseline_blocked`), `closes`; Ratify posts to `/api/holes/{key}/ratify` and the ratified state comes from `/api/ratified`.
- Bench: holes proven against tool calls from C5 v1.6 `found`, log scale, plus the results table.
- Approved changes from the UI1 prototype: holes grouped by goal, bench as curves, five phases, data-source label in place of "Prototype on fixture data".

To test, from `web/`:
- Real API (after AP1 merges): `npx playwright test`. It starts uvicorn with `BYLAW_REPORTS_DIR`, `BYLAW_CACHE_DIR` and `BYLAW_RATIFIED_DIR` in one tmp dir, and Vite. `e2e/smoke.spec.ts` runs an offline airline audit, then places a stored report with amendments (newer mtime) and ratifies on it (REQ-UI2-2, C9 v1.2).
- Without the API: `E2E_MOCK=1 npx playwright test` (e2e/mock.ts: a real offline EX1 report, reclassified per 01 v1.7 with the gold tasks of the adjudication decision; amendments, backtests and bench numbers are placeholders). The smoke opens the first finding: Class A if the report has one, else Class B (airline has no Class A under v1.7).
- `e2e/screens.spec.ts` writes `.artifacts/reports/ui2-*.png` at 1440 and 390 and fails if a page scrolls sideways (REQ-UI2-3).
