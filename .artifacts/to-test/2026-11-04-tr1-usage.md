# TR1: usage and cost traceability

## Problem

Muse usage and its cost were recorded in several committed files (run stats, the DM3 summary, PA1 run files) and summed only inside `video/figures.py` on the unmerged `video/vd4` branch. The app had no route that shows what was spent and on what, so the contract's requirement of a traceable cost (REQ-TR1-1..8, `docs/plan/06-showcase/tr1-contract.md`) was not met. The live counter also kept only a total, so a live cost could not follow the input/output price.

## Root cause

- `bylaw/live.py:25` (old): `USAGE = {"tokens": 0}`, input and output summed into one counter at `bylaw/live.py:57` (old).
- `bylaw/api.py`: no `/api/usage` route and no ledger file under `reports/`.

## Change

- `bylaw/live.py:26`: `USAGE` also counts `input_tokens` and `output_tokens`; `tokens` keeps its meaning (their sum), so `/api/live/status` and the token cap are unchanged.
- `bylaw/api.py:354`: `GET /api/usage` per the contract. Reads `<reports>/usage.json`, computes each entry's `cost_usd` and the totals; `live` is `/api/live/status` plus the split and its cost.
- `scripts/usage_ledger.py`: stdlib generator; `uv run python scripts/usage_ledger.py` writes `reports/usage.json` from `reports/csdemo.json`, `reports/airline.json`, `reports/airline.bench.json` (no tokens recorded, so no entry), `reports/live/dm3-summary.md` (DM3, DM4, DM5 tables; DM4 review and DM5 amend calls) and the `reports/live/*.json` files with `usage` (PA1). Committed output: `reports/usage.json`.
- `docs/plan/06-showcase/tr1-contract.md`: copy of the frozen contract.

## Ledger total versus VD4

VD4 `video/figures.py` total: 629,630 tokens. Ledger total: 704,032 tokens, cost 1.3455 to 1.8027 USD (`.scratch/after/tr1-usage/route-total.txt`). Differences, all entries else equal:

| Entry | VD4 | Ledger | Why |
|---|---|---|---|
| airline audit (`reports/airline.json`, 7 calls) | absent | +120,756 | committed run stats with tokens; VD4 counted only csdemo |
| LV1 live smoke, 2 runs | 25,626 | absent | source is a change note (`.artifacts/tested/2026-11-01-lv1-live-session.md`), not a record in the brief's list; `reports/live/lv1-smoke.json` carries no usage |
| VD4 live D1 session | 20,728 | absent | `reports/live/vd4-live-d1.json` and `video/vd4-live-d1.usage.json` exist only on `video/vd4`, not committed on this branch |
| DM2 amend and live runs | 0 (not recorded) | absent | no usage recorded |

629,630 + 120,756 - 25,626 - 20,728 = 704,032.
